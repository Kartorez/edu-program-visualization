# Educational Program Visualization

Інструмент для візуалізації освітніх програм, матриць компетентностей та результатів навчання. Платформа дозволяє студентам та викладачам наочно бачити структуру навчання, взаємозв'язки між дисциплінами та їх вплив на формування професійних навичок.

## Основні можливості

- **Інтерактивний навчальний план**: Візуалізація дисциплін у вигляді графа з відображенням семестрів та логічних зв'язків (пререквізитів).
- **Матриця компетентностей**: Зручна таблиця взаємозв'язку між дисциплінами та загальними/спеціальними компетентностями (ЗК/СК).
- **Матриця результатів навчання**: Візуалізація того, які програмні результати навчання (РН) забезпечує кожна дисципліна.
- **Розумна фільтрація**: Миттєвий пошук по дисциплінах та фільтрація матриць за типами компетентностей.
- **Експорт у PDF**: Можливість завантаження навчального плану та матриць у форматі PDF для друку.
- **Панель керування (CMS)**: Повноцінна адмінка для управління дисциплінами, компетентностями та групами вибіркових предметів.

## Технологічний стек

- **Frontend**: [Next.js 15](https://nextjs.org/) (App Router), [React 19](https://react.dev/), [SCSS Modules](https://sass-lang.com/).
- **Backend/CMS**: [Payload CMS 3.0](https://payloadcms.com/).
- **База даних**: [PostgreSQL](https://www.postgresql.org/).
- **Графи**: [@xyflow/react](https://reactflow.dev/) (React Flow).
- **PDF Generation**: [Puppeteer](https://pptr.dev/).
- **Інфраструктура**: [Docker](https://www.docker.com/) & Docker Compose.

## Налаштування

### 1. Змінні оточення
Створіть файл `.env` у корені проекту за прикладом:
```env
DATABASE_URL=postgres://user:password@localhost:5432/db_name
PAYLOAD_SECRET=your_super_secret_key
```

### 2. Локальна розробка
```bash
# Встановлення залежностей
npm install

# Запуск у режимі розробки
npm run dev
```

### 3. Запуск через Docker (рекомендовано)
Для швидкого розгортання всього стеку (додаток + PostgreSQL) використовуйте Docker Compose:
```bash
docker-compose up --build
```
Це автоматично запустить додаток на порту `3000` та PostgreSQL.

## Використання

- **Адмін-панель**: доступна за адресою `/admin`.
- **Візуалізація плану**: основна сторінка `/plan`.
- **Матриці**: розділи `/plan/competencies` та `/plan/results`.
