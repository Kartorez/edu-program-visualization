# Візуалізація освітніх програм (Educational Program Visualization)

Сучасна платформа для візуалізації навчальних планів, керування силабусами та аналізу матриць компетенцій. Побудована на базі **Payload CMS 3.0** та **Next.js 15**.

## Основні можливості

- **Інтерактивний навчальний план**: Візуалізація дисциплін у вигляді графа та структурованого списку за семестрами.
- **Матриці відповідності**:
  - Матриця компетентностей (ЗК/СК).
  - Матриця результатів навчання (РН).
  - Автоматичне підсвічування взаємозв'язків при наведенні.
- **Розумний парсер силабусів**: Автоматичне вилучення даних з PDF-файлів силабусів (теми, кредити, години, компетенції, реквізити).
- **Керування зв'язками**: Двостороння синхронізація пререквізитів та постреквізитів між дисциплінами.
- **Гнучка адмін-панель**: Потужна CMS для наповнення бази дисциплін, кафедр та освітніх програм.
- **Адаптивний інтерфейс**: Платформа повністю оптимізована для смартфонів та планшетів, забезпечуючи зручний доступ до навчальних планів на будь-якому пристрої.

## Технологічний стек

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript.
- **Backend/CMS**: Payload CMS 3.0 (Beta).
- **Database**: PostgreSQL з використанням Drizzle ORM.
- **Styling**: SCSS (Vanilla CSS approach) + Lucide Icons.
- **Parsing**: Інтеграція з зовнішнім мікросервісом для аналізу PDF.
- **Deployment**: Docker & Docker Compose.

## Встановлення та запуск

### Попередні вимоги
- Node.js 20+
- Docker & Docker Compose (рекомендовано)

### Швидкий запуск через Docker
```bash
# Клонування репозиторію
git clone https://github.com/kartorez/edu-program-visualization.git
cd edu-program-visualization

# Налаштування середовища (створіть .env на основі .env.example)
cp .env.example .env

# Запуск всього стеку (App + DB)
docker-compose up --build
```
Після запуску додаток буде доступний за адресою `http://localhost:3000`.

### Запуск для розробки (без Docker)
```bash
# Встановлення залежностей
npm install

# Запуск бази даних (якщо не через Docker)
# Переконайтеся, що DATABASE_URL у .env вказує на ваш Postgres

# Запуск dev-сервера
npm run dev
```

## Використання

1. **Адмін-панель**: Перейдіть до `/admin` (створіть першого користувача при першому запуску).
2. **Парсинг силабусів**: У редакторі дисципліни натисніть кнопку "Завантажити силабус" (UI Field) для автоматичного заповнення полів.
3. **Навігація**: Використовуйте бічну панель для швидкого перемикання між семестрами та перегляду деталей дисциплін.
4. **Матриці**: Розділи матриць дозволяють візуально оцінити покриття освітньої програми компетентностями.
